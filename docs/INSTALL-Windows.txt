VESSEL 2.0 for Windows (64-bit)
===============================

VST3
----
Copy the whole VESSEL.vst3 folder to:

    C:\Program Files\Common Files\VST3\

Keep the folder intact: the 379 wavetables live inside it, in VESSEL.vst3\Contents\Resources\Wavetables.
Then rescan plug-ins in your DAW. VESSEL shows up as an instrument by iisben.

Standalone
----------
Run Standalone\VESSEL.exe. Keep the Wavetables folder next to it.
Connected MIDI keyboards auto-connect on launch (audio input is disabled by default),
and you can also play using your computer keyboard (KEYS button: A-' white, W-P black, Z/X octave, C/V velocity).

User Presets & Settings
-----------------------
Stored automatically in:

    %APPDATA%\VESSEL_II\

Notes
-----
- All 379 CC0 wavetables and 116 factory presets (96 V1 + 20 V2 flagship) are bundled.
- The build is not code-signed, so Windows SmartScreen may warn on first launch.
  Choose "More info", then "Run anyway".
